## Descripción del proyecto

Sistema web para la gestión integral de obras de construcción: proyectos, compras de material, salidas de bodega, inventario, cotizaciones por proveedor y control de usuarios con roles diferenciados.

## Cómo navegar el prototipo

1. Ir a la carpeta `/prototipo`
2. Abrir `index.html` directamente en Chrome o Edge
3. No requiere instalación ni servidor local
4. Credenciales de prueba: `admin@protocem.mx` / `protocem2025`

**Pantallas:** Login · Dashboard · Proyectos · Compras · Salidas de Material · Inventario · Cotizaciones · Usuarios

## Estructura del repositorio

```
/prototipo        — Archivos HTML/CSS/JS del prototipo navegable
/documentacion    — Especificación Final, Matrices de Requerimientos y Trazabilidad
/diagramas        — Diagramas AS-IS, TO-BE y ER (imagen + archivo MySQL Workbench)
/minutas          — Minutas de entrevistas iniciales y validación del prototipo
```
